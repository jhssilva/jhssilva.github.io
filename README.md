This repository contains the source code for my personal portfolio website, hosted on GitHub Pages.

It is based on the excellent [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme.

## Features

- **About Me**: Introduction and bio.
- **CV/Resume**: Detailed professional experience and education.
- **Portfolio**: Showcase of projects including web development and data science work.
- **Blog**: Technical articles and updates.
- **Publications**: List of academic theses and papers.
- **Repositories**: Integration with GitHub to display open-source contributions.
